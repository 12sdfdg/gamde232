# Roblox project

Проект синхронизируется с Roblox Studio через [Rojo](https://rojo.space).

## Структура

- `src/server` → ServerScriptService (серверные скрипты)
- `src/client` → StarterPlayerScripts (клиентские скрипты)
- `src/shared` → ReplicatedStorage (общие модули)

## Запуск

```bash
rojo serve
```

Затем в Roblox Studio: плагин Rojo → Connect.
