# 🏁 Turbo Race Clicker

Roblox-гра в жанрі «клікер + забіг» (у дусі Race Clicker / Speed Simulators): клікаєш і набираєш швидкість, автоматично біжиш трасою з 40 зонами, отримуєш виграші, вилуплюєш улюбленців, робиш ребьорт і стаєш ще швидшим.

Карту, UI й ефекти побудовано кодом, тож гра працює одразу після відкриття, без жодного ручного моделювання.

## 🚀 Як запустити

**Варіант 1, найпростіший:** відкрий `TurboRaceClicker.rbxlx` у Roblox Studio і натисни **Play**.

**Варіант 2, для розробки через [Rojo](https://rojo.space):**
```bash
rojo serve            # синхронізація з Studio (потрібен плагін Rojo)
rojo build -o TurboRaceClicker.rbxlx   # перезібрати файл місця
```

## ✅ Що зробити перед релізом

1. **Game Settings → Security → Enable Studio Access to API Services**, щоб прогрес зберігався (DataStore).
2. Створи в Creator Hub **Game Passes** і **Developer Products** та впиши їхні ID у `src/shared/Config.lua` (`Config.GamePasses`, `Config.Products`). Поки там стоїть `0`, у Studio покупки видаються безкоштовно для тестування, а в живій грі показується «coming soon».
3. Створи справжню Roblox-групу і впиши її ID у `Config.GROUP_ID` (+10% швидкості учасникам).
4. Додай власні промокоди в `Config.Codes` і публікуй їх в описі гри й у групі з кожним оновленням.
5. Перед відкритим релізом зміни `Config.DATASTORE_NAME` (наприклад, на `PlayerData_v2`), щоб скинути прогрес тестерів.

| **Повернення щодня** | 7-денна серія щоденних нагород (скидається, якщо пропустити день) |

| **Монетизація** | 7 геймпасів (VIP, 2x Speed, 2x Wins, Auto Clicker, +3 Pet Slots, Lucky Eggs, Triple Hatch), пакети виграшів, які масштабуються з прогресом, і бусти на 15 хв |

| **Аналітика** | `AnalyticsService`: воронка онбордингу (вхід → клік → забіг → яйце → ребьорт), економіка Wins, прогресія ребьортів |

## 🔒 Надійність

- Усі нагороди рахуються **на сервері**. Клієнт лише малює забіг, і підробити позицію чи дистанцію неможливо.
- Сервер обмежує кліки до 20/с, тож сторонні автоклікери не дають переваги.
- Блокування сесії в DataStore не дає дублювати чи губити прогрес під час переходу між серверами.
- Покупки ідемпотентні: `ProcessReceipt` запам'ятовує ID чеків, тому товар не видається двічі.
- Шанси випадіння з яєць показано над кожним яйцем, як того вимагають правила Roblox щодо випадкових предметів.

## 📁 Структура

```
src/shared/   Config (весь баланс і ціни), Format, Net (remotes)
src/server/   DataService, PlayerState, RaceService, PetService,
              ShopService, RewardService, LeaderboardService, MapBuilder
src/client/   Hud, Panels (меню), Race (анімація забігу), PetsVisual, Effects, UI
```

## 📈 Як вивести гру в топ

Код дає міцну основу, але в топ Roblox гру виводять інші речі:

1. **Іконка й мініатюри**: найважливіше для CTR. Яскраві, з великим персонажем і числами (`999M SPEED!`). Тестуй кілька варіантів через Thumbnail A/B у Creator Hub.
2. **Оновлення щотижня**: нові світи, яйця, улюбленці, події. Алгоритм Roblox підтримує ігри, які оновлюються.
3. **Метрики в Creator Hub → Analytics**: D1-утримання (ціль 25%+), середня тривалість сесії, конверсія в платників. Покращуй найслабше місце воронки.
4. **Реклама (Sponsored Experiences)**: старт із невеликого бюджету, щоб набрати перших гравців і дані.
5. **Спільнота**: група, Discord, нові коди з кожним оновленням.
6. **Власні звуки, моделі улюбленців і карта**: заміни емодзі-улюбленців і процедурну карту на моделі. Механіки при цьому лишаються.
